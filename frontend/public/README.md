# Public assets

Drop your static files here. Referenced from data/site.ts:

- `resume.pdf`  → your resume (linked by the "Resume" button)
- `og.png`      → 1200×630 social-share image (Open Graph / Twitter card)
- `favicon.ico` → place in /app instead (Next.js App Router convention)

## Project screenshots
Add project thumbnails here, e.g. `/public/projects/nimbus.png`,
then set the `image` field in data/projects.ts to `/projects/nimbus.png`.

If you leave `image` undefined, the card shows a clean typographic
placeholder — no broken images.
